# SAA - 智能医疗评估问卷自动填空助手

基于OCR视觉定位与规则引擎的医疗评估问卷自动填空系统。

## 界面原型演示

[在线演示（GitHub Pages）](https://linagaya.github.io/SAA/)

四步交互演示：
1. **Step 1 读取剪贴板** — 模拟读取护士笔记
2. **Step 2 生成笔记** — 基于规则引擎生成清洁英文Session Note
3. **Step 3 自动选选项** — OCR定位 + 自动勾选下拉选项
4. **Step 4 安全守卫** — S8不覆盖规则演示

## 项目概述

面向美国长期护理机构的UAS-NY评估问卷自动化工具，通过OCR视觉识别定位界面元素，结合规则引擎自动完成选项勾选和Session Note生成，将单次评估录入时间从60分钟压缩至15分钟，选项准确率≥99%。

## 功能特性

- **OCR视觉定位** — 无需API接入，纯视觉识别兼容任何远程桌面环境
- **规则引擎** — 14个Section独立模板，严格按医疗规范生成英文Note
- **S8不覆盖原则** — 已有选项/Note绝不覆盖，仅追加或跳过
- **S10零中文红线** — 实战输出纯英文，无中文内容
- **逐Case检查提醒** — 每个病例完成后暂停，等待人工复核

## 技术栈

Python + PyTesseract + OpenCV + PyAutoGUI + 规则引擎模板
